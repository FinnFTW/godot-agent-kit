# Agent Kit: the tuning sheet

Every number you can tune, what you would notice when you change it, and what it actually does.

- **Where the numbers live:** in the `.tres` files each section names. Open one in Godot and change a number in the Inspector.
- **Hover a setting's name in the Inspector** and the same text as here shows up as its tooltip.
- **The Default column is the script's default.** A setting missing from a `.tres` file means the default: Godot only writes the values you changed.

This file is generated by `addons/agent_kit/tuning_sheet.gd`; edit the `##` line above the setting in its script instead, then run it again.
